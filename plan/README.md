## Правила

- Источник правды по продукту — `product-spec.md`. HTML — его визуальная копия, правятся вместе.
- Решения сначала записываются в спеку, потом идут в код.
- Числа в ответах жюри должны быть проверяемы: либо замер в `CLAUDE.md`, либо «не измерено».
- Персональные данные (ФИО, ПИНФЛ, почты, номера телефонов) сюда не кладём.
