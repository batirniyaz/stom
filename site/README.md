# Прототип Stomadent (сайт)

Статический сайт без сборки. Запуск: `cd site && python3 -m http.server 8765`, открыть http://localhost:8765.

Экраны: вход врача (демо-код 1234) -> список пациентов -> профиль (обзор, снимки, история, заметки) -> загрузка снимка -> разбор с 3D, находками, чек-листом, чатом и заключением.
Состояние хранится в localStorage браузера. Пациенты, находки и ответы чата выдуманные.
Модель челюсти `model.glb` — публичный набор figshare 26965903, CC BY 4.0.
