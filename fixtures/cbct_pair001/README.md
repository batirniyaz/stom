# Данные для разработки: кейс КЛКТ

Один готовый кейс КЛКТ, чтобы фронт, PDF и мобильное приложение можно было
делать **без моделей и без снимков клиники**.

## Откуда

Набор пар «КЛКТ + интраоральный скан», figshare 26965903, лицензия **CC BY
4.0**. Лицензия разрешает распространение при указании источника — поэтому
этот кейс в репозитории лежать может, а клинические снимки нет.

Здесь лежит не исходный том, а то, что посчитал наш конвейер: поверхность
(меш) и слой находок.

## Что внутри

| файл | что это |
|------|---------|
| `mesh_sp.glb` | поверхность всех структур, модель `sp`; ноды `tooth_<FDI>` на каждый зуб |
| `meta.json` | находки, план, зубная формула, сведения о кейсе |

## Чего здесь нет

Тома (`volume.mha`, 300+ МБ) и маски (`mask_sp.mha`, 150 МБ). Они нужны
только для срезов и пересчёта находок — то есть для того, что и так требует
моделей. Всё остальное считается по этим двум файлам.
