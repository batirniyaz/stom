# Diagnocat — Полный анализ продукта

## Что такое Diagnocat
Единая AI-платформа для стоматологической диагностики. Обрабатывает 2D/3D снимки, создаёт отчёты, 3D-модели, автоматизирует документирование приёмов.

---

## Основные продукты

### 1. Отчёт по снимкам (Radiology Report)
**Вход:** DICOM (КЛКТ), 2D (внутриротовые, ОПТГ)
**Выход:** Цветной PDF-отчёт с зубной формулой

- **60+ признаков** на КЛКТ, **40+** на 2D
- Кариес, периапикальные поражения (>90% точность), пародонтит, эндодонтия
- Скорость: 10с (2D), 30с (панорама), 4-6мин (КЛКТ)
- Цветовая кодировка: красный (патологии), фиолетовый (лечение), жёлтый (настороженность 30-50%)
- Экспорт STL для 3D-печати

### 2. 3D-модели (Super-imposition)
**Вход:** КЛКТ DICOM + интраоральные сканы
**Выход:** STL 3D-модели

- Автоматическая сегментация: зубы, пульпа, корневые каналы, пазухи, нижнечелюстной канал
- Суперимпозиция (наложение КЛКТ + IOS)
- Мультипланарная реконструкция (МПР)
- 3D-печать, CAD/CAM экспорт

### 3. Имплантат-отчёт
- Планирование имплантации
- Отдельный пакет (5/20/100 отчётов)

### 4. Ортодонтический отчёт
- 3D-цефалометрия
- Ортодонтическое планирование

### 5. Transcriptor
**Вход:** Аудио приёма (беспроводные микрофоны)
**Выход:** SOAP-запись, письмо пациенту, оценка коммуникации

- Speech-to-Text AI
- Автоматическая мед. карта (жалобы, анамнез, диагноз, план)
- Оценка по Калгари-Кембриджской модели
- До 75% экономии времени на документах

### 6. Статистика / Analytics
- Дашборды для руководителей
- Управление клиникой

### 7. Интеграции
- МИС (медицинские информационные системы)
- КТ/ОПТГ/визиограф оборудование
- Интраоральные сканеры

## Технические компоненты для аналога

### ML/AI компоненты (ядро)
1. **2D image classification/detection** — кариес, периапикальные поражения (CNN, YOLO/ResNet)
2. **3D segmentation** — КЛКТ DICOM → STL (U-Net 3D, nnU-Net)
3. **Speech-to-Text** — транскрипция приёмов (Whisper или API)
4. **NLP → SOAP** — генерация мед. карты из текста (LLM)

### Платформа
5. **DICOM viewer** — веб-просмотр снимков
6. **3D viewer** — STL визуализация в браузере (Three.js)
7. **PDF Report Generator** — генерация отчётов
8. **User management** — роли: врач, админ, пациент
9. **Billing/Subscription** — тарифы, лимиты

### Интеграции
10. **DICOM ingestion** — загрузка с КТ/ОПТГ аппаратов
11. **МИС integration** — API для мед. систем
12. **Storage** — DICOM файлы, STL модели (MinIO/S3)
