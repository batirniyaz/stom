# docs/ — справочные документы

Что не нужно для работы каждый день, но нужно, чтобы понять решения. Рабочий
журнал проекта (замеры, пороги, отрицательные результаты) — `CLAUDE.md` в
корне; план хакатона и материалы к защите — в `plan/`.

## Актуальное

| Файл | Что это |
|---|---|
| [ROADMAP.md](ROADMAP.md) | Что не доделано по каждому типу снимков, что для этого нужно (код / разметка / клиника / обучение) и в каком порядке делать. Обновлён 17.09.2026 — приоритеты с тех пор сместились под показ, сверять с `plan/status.md` |
| [DIAGNOCAT_ANALYSIS.md](DIAGNOCAT_ANALYSIS.md) | Разбор конкурента: какие находки он выдаёт, с какой заявленной точностью, что из этого проверяемо. Используется как целевой набор функций |

Рядом, но лежит у своих данных:

- [`research/datasets/AVAILABLE_2D_DATASETS.md`](../research/datasets/AVAILABLE_2D_DATASETS.md) — обзор доступных 2D-датасетов с лицензиями.
- [`research/datasets/CBCT_PULP_RESEARCH.md`](../research/datasets/CBCT_PULP_RESEARCH.md) — разбор наборов с разметкой пульпы.
